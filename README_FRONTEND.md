# 🎓 Sistem Informasi Akademik (SIAKAD) - Frontend Repository

Repo ini berfokus pada **antarmuka pengguna (UI)** dan interaksi client-side menggunakan kerangka kerja modern.

## 🚀 Teknologi yang Digunakan

- **Frontend Framework**: React.js (via Inertia.js)
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Animation**: Framer Motion

## 📂 Struktur Folder Utama

- `resources/js/Pages` - Halaman-halaman utama aplikasi (Dashboard, Login, dll).
- `resources/js/Components` - Komponen UI yang dapat digunakan kembali (Navbar, Sidebar, Card).
- `resources/js/Layouts` - Tata letak dasar halaman (contoh: AuthenticatedLayout, GuestLayout).
- `public` - Aset statis seperti gambar, font, dan favicon.

## 🛠️ Cara Menjalankan (Development)

Pastikan Backend (Laravel) sudah berjalan, kemudian jalankan server vite:

```bash
npm install
npm run dev
```
